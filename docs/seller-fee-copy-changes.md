# 판매 수수료 10% 고정 변경 문구 목록

공통 안내: 판매 수수료는 월 판매액(구매 확정 기준)의 10%예요. 쿠폰 할인 전 상품 금액을 기준으로 하며 배송비는 제외해요.

- src/components/SellerMonthlySales.tsx: 조건부 수수료 안내를 공통 안내로 변경. 상품 금액, 수수료, 정산 예정을 판매액, 수수료 10%, 지급 예정액으로 변경.
- src/pages/account.tsx: 입점 승인 10% / 0%를 10%로 변경하고 공통 안내 적용. 정산 주기 D+7을 월별로 변경. 정산 FAQ에 월별 구매 확정 기준과 공통 안내 명시.
- src/pages/seller.tsx: 고객지원 수수료 안내와 판매자 약관 동의에 공통 안내 적용. 상품 결과의 D+7 입금 안내를 구매 확정 기준 월별 정산으로 변경.
- src/pages/wizard.tsx: 판매 등록 최종 확인에 공통 안내 추가.
- src/pages/auth.tsx: 서비스 이용 안내에 공통 안내, 월별 집계, 원 미만 버림, 판매액에서 수수료를 차감한 지급 예정액 설명 추가.
- src/pages/sellerBank.tsx: 목업 정산 주기를 월별 (구매 확정 기준)으로 변경.
- src/api/sellerOrders.ts: 판매율 조건 주석을 고정 10% 및 원 미만 버림 설명으로 변경.
- docs/api-gap.md 및 docs/api-check.md: 정산 API 없음 또는 mock 유지 설명을 기존 월별 정산 API와 고정 수수료 정책으로 수정.
- 관련 단위 테스트와 tests/seller-result-live.spec.ts: 조건부 수수료 테스트 제목 및 기대값을 고정 수수료 정책으로 변경.

기존 월별 정산 API와 화면 배치를 유지한다. 판매 수량 게이지의 판매율과 docs/반영점검표.md의 작업 진행률 90%는 수수료 정책과 무관하여 유지한다. 목업 대시보드와 상품 결과도 구매 확정 기준 월별 집계에 고정 10%를 적용한다.
